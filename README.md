# Simple Pad

Lightweight text editor with Batch syntax highlighting.

## Install on Linux Mint

```bash
curl -fsSL https://github.com/klcenka9/simple-pad/releases/latest/download/simple-pad_1.0.0_all.deb -o /tmp/simple-pad.deb && sudo apt install /tmp/simple-pad.deb
```

Run it from the application menu or with `simple-pad`.

## Build a package

```bash
./build-deb.sh
```
